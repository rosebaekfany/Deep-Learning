This repository contains all the materials, assignments, and final project completed as part of the **Deep Learning course**.

## 📝 Final Project

The final project was completed in **two phases**:

### 🔹 Phase 1 – Report (`deep_project_phase1.pdf`)

* A comprehensive **literature review and analysis** of **multi-object tracking (MOT) algorithms**.
* Covers well-known methods:

  * **SORT (Simple Online and Real-time Tracking)**
  * **Deep SORT**
  * **FairMOT**
  * **ByteTrack**
* Applications in **sports video tracking** (players, referees, ball).
* Discussion of **tracking performance metrics**: MOTA, IDF1, Recall, Precision, Fragmentation.
* Review of benchmark datasets: **SportsMOT, MOT17, DanceTrack, PoseTrack**.
* Identifies **key challenges** such as occlusion, scale variation, and illumination changes.
* Recommendations include **transformers for trajectory prediction**, **multi-scale frameworks**, and **model optimization** for real-time sports analysis.

### 🔹 Phase 2 – Implementation (`deep-project_phase2_final_ZahraMaleki.ipynb`)

* Practical **implementation in Python (Jupyter Notebook)**.
* Implements dataset loading, preprocessing, and tracking experiments.
* Demonstrates **multi-object tracking workflows** and evaluates performance.
* Includes example usage with **SportsMOT dataset**.
